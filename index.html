Shortcuts and good-to-knows

While setting up or recording

R start or stop recording · Space pause and resume · M mute the mic · C show or hide the camera

In the editor

Space play and pause · I set the trim start · O set the trim end · ← → nudge by a second (hold Shift for 5) · Home jump to the trim start

Recording other apps

The recorder keeps drawing frames even when this tab sits in the background, so you can switch away freely. If you can, park this tab on a second monitor to watch the timer.

Computer sound

Browsers only hand over system or tab audio if you tick the audio box inside the sharing dialog, and on Windows that option appears for a whole screen or a tab, not for a single window.

Sharing the file

WebM plays in any browser, Slack, Discord and VLC. If the person receiving it needs a file for PowerPoint or iMovie, pick MP4 in the format list when your browser offers it.
